# ratelane-docs

Documentation site for [Ratelane](https://ratelane.dev) — built with [Fumadocs](https://fumadocs.dev) and Next.js.

Live at [docs.ratelane.dev](https://docs.ratelane.dev)

## Structure

```
content/docs/       # MDX pages
src/app/            # Next.js app router
src/components/     # MDX component overrides
src/lib/            # Source config, shared constants
```

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Contributing

Found a mistake or want to improve the docs? Open an issue or submit a PR — contributions welcome.

## Analytics

The Analytics page shows aggregated traffic data across your fleet:

- **Request volume** — total requests over time, by route or instance
- **Rate limit hits** — how often limits are being triggered
- **Latency** — p50, p95, p99 per route
- **Top IPs** — highest-volume source IPs

Use the time range selector to view last 1h, 24h, 7d, or 30d.

## Request logs

The Logs page shows individual request events with:

- Timestamp
- Route matched
- Source IP
- Response status
- Whether a rate limit was enforced

Logs are retained for 30 days on all paid plans.

## Filtering

Filter logs by:

- Route
- Instance
- Status code
- IP address
- Date range
